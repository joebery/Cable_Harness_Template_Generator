# Cable Harness Template Generator

![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg) ![License](https://img.shields.io/badge/license-MIT-brightgreen.svg)

## Description

The **Cable Harness Template Generator** is a Python-based tool designed for generating parametric cable harness layout drawings as PDFs. This tool is specifically tailored for manufacturing, documentation, and bench layout, providing users with a robust solution for visualizing cable harness designs.

## Features

- **Parametric Design**: Easily adjust parameters to customize cable harness layouts.
- **PDF Output**: Generate high-quality PDF drawings for documentation and manufacturing purposes.
- **User-Friendly**: Designed with simplicity in mind, making it accessible for users with varying levels of technical expertise.
- **Multiple Templates**: Comes with various template versions to suit different needs and preferences.

## Installation

### Prerequisites

- Python 3.8 or higher
- ReportLab library

### Clone the Repository

```bash
git clone https://github.com/joebery/Cable_Harness_Template_Generator.git
cd Cable_Harness_Template_Generator
```

### Configure the Environment

Install the required dependencies using pip:

```bash
pip install reportlab
```

### Run the Application

Execute the desired template script:

```bash
python template_gen.py
```

## Usage

To generate a cable harness layout, simply run one of the provided scripts. For example, to use the first template:

```bash
python template_gen_1.0.py
```

This will create a PDF file in the current directory with the layout based on the parameters defined in the script.
